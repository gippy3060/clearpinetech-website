Try it yourself first

Reconnecting an HP printer to Wi-Fi

Menus differ between models. Your printer's manual or screen will show the exact names. If you get stuck, call us.

  1. Print a wireless network test report. On the printer's control panel, open Setup or Wireless settings and choose to print the wireless network test report. It shows whether the printer is connected, the network name and its address.
  2. Check the network name. Make sure the report shows your home Wi-Fi name, not a neighbour's or a guest network. Many HP printers can join only a 2.4 GHz network, so check your model's specifications if your router combines or splits bands.
  3. Restart in order. Turn off the printer, router and computer. Turn on the router, wait two minutes, then the printer, then the computer.
  4. Run the wireless setup wizard again. In the printer's Wireless settings, run the Wireless Setup Wizard, pick your network and enter the Wi-Fi password carefully, noting capital letters.
  5. Re-add the printer. In Windows or macOS, remove the printer and add it again, or set it up from the HP Smart app.

HP also offers a free Windows tool called HP Print and Scan Doctor, which can check for common printing and scanning faults. Download it only from HP's own website. For general steps that work with any brand, see our printer help page.

Questions

HP printer help FAQ

My HP printer says offline. How do I fix it?

Most often the printer has lost its Wi-Fi connection or its address has changed. Print a wireless network test report from the printer's menu, check it shows your home network, then restart the printer and router. If Windows still says offline, the Use Printer Offline setting or the printer port may need fixing. We can walk you through each step or do it with you in a remote session.

Can you set up my HP printer on Wi-Fi?

In most cases, yes. We guide you through joining the printer to your Wi-Fi from its screen or buttons, install the printer software on your computer, and print a test page. With your permission we can also set up the HP Smart app on your phone.

What is the HP Smart app and do I need it?

HP Smart is the free app from HP for setting up and using many HP printers from a phone, tablet or computer. You do not always need it to print, but it is the easiest way to set up many newer models. Some features, such as Instant Ink, need an HP account.

My HP printer rejects my ink cartridge. Can you help?

Sometimes. Messages about a cartridge problem can be caused by a dirty contact, a cartridge not seated properly, or a printer that only accepts certain cartridges (for example, when it is signed up to a cartridge subscription or has had a firmware update). We can help you work out which it is. We cannot override a printer's cartridge rules or supply cartridges.
