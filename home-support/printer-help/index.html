Try it yourself first

Fixing "printer offline" in Windows

These steps solve many cases at no cost. If they do not, call us.

  1. Restart everything in order. Turn off the printer, router and computer. Turn on the router, wait a couple of minutes, then the printer, then the computer.
  2. Check the printer is on your Wi-Fi. From the printer's menu, print a network configuration (or Wi-Fi test) page. It should show your network name and an IP address. If it shows none, the printer needs to be reconnected to Wi-Fi.
  3. Make sure you are on the same network. Your computer and printer must be on the same Wi-Fi. Guest networks and some extender setups can block printers.
  4. Untick "Use Printer Offline". In Windows Settings, go to Bluetooth & devices, then Printers & scanners, pick your printer and open the print queue. In its Printer menu, make sure Use Printer Offline is not ticked.
  5. Clear the print queue. Cancel all documents. A single stuck job can make a printer look offline.
  6. Check the port. In Printer properties, on the Ports tab, the port should match the IP address on the network page. Routers sometimes give the printer a new IP address after a restart.
  7. Remove and re-add the printer. Delete it in Windows, then add it again, or install the driver from the manufacturer's website.

On a Mac, open System Settings, then Printers & Scanners, remove the printer with the minus button and add it again. Newer printers usually work through AirPrint without a separate driver. See all home support options.

Questions

Printer help FAQ

Why does my printer say offline when it is turned on?

Usually the printer has dropped off the Wi-Fi network, its IP address has changed so the computer is looking in the wrong place, or the Use Printer Offline setting is ticked in Windows. Restarting the printer and router, then checking the printer's network page, solves many cases.

Can you set up my printer over the internet?

In most cases, yes. With your permission we connect to your computer, install the driver, join the printer to your Wi-Fi and print a test page. You may need to press a button or read a code on the printer's screen, and we will guide you.

How much does remote printer help cost?

A one-time remote support session is a flat $100 CAD, available anywhere in Canada. If we cannot fix the problem, you are not charged.

Are you affiliated with HP, Brother, Canon or other printer makers?

Can you fix a printer that has a hardware fault?

Remote support cannot repair physical problems such as worn rollers, a broken print head or a failed motor. We can tell you whether the issue looks like software or hardware. If we cannot fix the problem, you are not charged.
