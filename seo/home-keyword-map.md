# Keyword map: home user tech support

Scope: `/home-support/` pages and home-user blog posts. Remote-only service for Canada and the USA,
$100 CAD flat per session, nothing if it can't be fixed. Shared reference for the *home remote support*
routine; log page work in `seo/home-support-log.md`. Created 2026-11-13.

Rules: don't promise in-home/on-site visits or same-day service (not offered or not confirmed). Brand
pages must keep the "independent, not affiliated" disclaimer. "Near me" searches are won mainly by the
Google Business Profile, so pages target the problem, not the phrase "near me".

Priority: A = build/strengthen first, B = next, C = later. Status: `todo` / `done (URL)`.
